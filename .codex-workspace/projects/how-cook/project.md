# how-cook

## App Name

How Cook?

## Vision

Help home cooks prepare several dishes in one meal by turning selected dishes and kitchen resources into a clear cooking timeline and guided timer flow.

## Target User

Home cooks, especially beginners or busy cooks, who prepare 2-4 dishes for a meal and want each dish to finish at the right time.

## Current Phase

Project intake for Phase 0 MVP.

## Source Inputs

- `meal-flow-planner-phase-0-codex-plan.md`
- `meal_flow_planner_ui_preview.jsx`

## Assumptions

- Phase 0 is a local-first webapp prototype.
- The app name is exactly `How Cook?`.
- The project id is `how-cook`.
- The MVP should use Next.js, React, TypeScript, and Tailwind CSS unless implementation constraints make a smaller local scaffold safer.
- No account system, backend, database, cloud sync, AI parser, recipe import, payments, or social features are included in Phase 0.
- Demo dish data should use readable Vietnamese names and labels, even if the input preview file contains mojibake text.
